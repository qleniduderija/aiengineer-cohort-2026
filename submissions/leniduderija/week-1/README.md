Task for WEEK 1 is to build a CLI that takes a natural language question about a codebase (Q's or any repo) and answers it using the Anthropic API.

# Core Technical Requirements
 - Multi-turn conversation – Maintain dialogue context across multiple turns.
 - Streaming output – Render responses in real-time as they are generated by the API.
 - Basic error handling – Gracefully manage operational anomalies without breaking the execution flow.
 - Token counting and cost logging – Calculate and log token consumption and exact financial cost per query.

# Acceptance Criteria
 - The tool works and successfully runs on a real repo of your choice.
 - The system explicitly prints token counts and per-query cost upon completion.
 - The application handles API errors natively without crashing.
 - The project repository includes a clear and comprehensive README documentation file.
